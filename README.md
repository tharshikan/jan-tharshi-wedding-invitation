# Tharshikan & Jananny — Wedding Invitation

Interactive invitation: envelope → vellum gatefold → two-sided card (English / Tamil).

Static site, no build step. Open `index.html` or visit the GitHub Pages URL.

Personalize a link by adding the guest name after `#` — underscores become spaces, `~` becomes `&`:

```
https://tharshikan.github.io/jan-tharshi-wedding-invitation/#The_Kumar_Family
https://tharshikan.github.io/jan-tharshi-wedding-invitation/#Priya_~_Arun
```
